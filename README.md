# Smart Home Control App

This is a first-year university programming project built with Python and Tkinter.

## Features

- Smart Plug
- Smart Air Fryer
- Smart Speaker
- Add devices
- Delete devices
- Toggle devices on/off
- Edit device settings

## Technologies Used

- Python
- Tkinter
- Object-Oriented Programming
